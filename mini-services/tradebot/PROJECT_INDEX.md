## معرفی پروژه

### **هدف اصلی**
این پروژه یک **سیستم تحلیل خودکار سیگنال‌های بازار ارزهای دیجیتال** است که برای تبادل‌گران و سرمایه‌گذاران طراحی شده است.

### **قابلیت‌های اصلی**
- 📈 **تجزیه و تحلیل داده‌های بازار** با استفاده از شاخص‌های تکنیکال (RSI, ATR, SMA)
- 🎯 **تولید خودکار سیگنال‌های ورود** بر اساس شرایط بازار
- 🤖 **اتوماسیون معاملات** برای باز و بسته‌سازی خودکار پوزیشن‌ها
- 💾 **ذخیره‌سازی داده‌ها** در پایگاه داده SQLite
- 🔐 **اتصال امن به API** صرافی Toobit با امضاء HMAC-SHA256
- 📊 **نمودارهای تعاملی** با ECharts برای مصورسازی بازار
- 🌙 **رابط کاربری تاریک** شبیه‌سازی شده با Tailwind CSS

## اجزاء اصلی

### **1️⃣ Backend Server (server.js)**

#### **مسئول:**
- پذیرش درخواست‌های HTTP از Frontend
- ارتباط امن با API صرافی Toobit
- مدیریت دیتابیس SQLite
- ارسال داده‌های بازار و وضعیت معاملات

#### **REST API Endpoints:**

```javascript
POST /api/history
├── INPUT: { symbol, apiKey, secretKey, baseUrl, limit }
├── OUTPUT: Array of trade history
└── مثال: دریافت معاملات قبلی برای نماد DOT-SWAP-USDT

POST /api/balance
├── INPUT: { apiKey, secretKey, baseUrl }
├── OUTPUT: { free: number, locked: number }
└── مثال: موجودی حساب کاربر

POST /api/current-price
├── INPUT: { symbol, apiKey, secretKey, baseUrl }
├── OUTPUT: { price: number, time: number }
└── مثال: قیمت فعلی BTC-SWAP-USDT

POST /api/trade
├── INPUT: Trade parameters
├── OUTPUT: { orderId, quantity, price }
└── مثال: ثبت یک معامله جدید
```

#### **نحوه کار:**
```
1. Frontend ارسال می‌کند: { symbol, apiKey, secretKey }
                    ↓
2. Server ایجاد می‌کند: Query String + HMAC-SHA256 Signature
                    ↓
3. Server درخواست می‌دهد: https://api.toobit.com/api/v1/futures/userTrades
                    ↓
4. Server دریافت می‌کند: JSON Response
                    ↓
5. Server ارسال می‌کند: به Frontend
```

### **2️⃣ Market Signal Analyzer (market-signal-analyzer.js)**

#### **مسئول:**
- تجزیه‌و‌تحلیل داده‌های بازار تاریخی
- محاسبه شاخص‌های تکنیکال
- تولید سیگنال‌های ورود (Long/Short)
- نمایش نمودارها و سیگنال‌ها

#### **کلاس:** `MarketSignalAnalyzer`

#### **خصوصیات:**
```javascript
this.historyData      // تاریخچه معاملات
this.marketData       // داده‌های شمعی‌خوانی (OHLC)
this.signals          // سیگنال‌های تولید شده
this.chart            // نمودار ECharts
```

#### **متدهای اصلی:**

| متد | ورودی | خروجی | توضیح |
|-----|-------|-------|--------|
| `fetchHistory()` | symbol | Array | دریافت معاملات قبلی |
| `fetchMarketData()` | symbol, interval | Array | دریافت داده‌های بازار تاریخی |
| `analyzeMarketData()` | - | void | تجزیه‌و‌تحلیل و تولید سیگنال |
| `renderChart()` | - | void | رسم نمودار با سیگنال‌ها |
| `calculateSignalStatus()` | signal | Object | وضعیت سیگنال (در انتظار/باز/بسته) |

#### **منطق تولید سیگنال:**

```
Step 1: دریافت 1000 شمع ساعتی
        ↓
Step 2: محاسبه شاخص‌های تکنیکال:
        ├─ RSI (14) - نسبت قدرت نسبی
        ├─ ATR (14) - میانگین دامنه واقعی  
        └─ SMA (50) - میانگین متحرک
        ↓
Step 3: تعیین حد‌های روزانه قبلی:
        ├─ بالاترین قیمت روز قبل
        └─ پایین‌ترین قیمت روز قبل
        ↓
Step 4: شرایط سیگنال Long:
        ├─ قیمت از پایین روز قبل بالاتر رود
        ├─ حجم معاملات بیش از 20% میانگین
        ├─ RSI < 50 (بازار نه خریدار/فروش‌شده)
        └─ ATR مثبت (نوسان معناداری وجود دارد)
        ↓
Step 5: شرایط سیگنال Short:
        ├─ قیمت از بالاتر روز قبل پایین‌تر رود
        ├─ حجم معاملات بیش از 20% میانگین
        ├─ RSI > 50 (بازار نه خریدار/فروش‌شده)
        └─ ATR مثبت (نوسان معناداری وجود دارد)
        ↓
Step 6: محاسبه Take Profit و Stop Loss:
        ├─ Long: TP = Price + (ATR × 20), SL = Price - (ATR × 6)
        └─ Short: TP = Price - (ATR × 24), SL = Price + (ATR × 4)
        ↓
Step 7: ذخیره سیگنال و رسم نمودار
```

### **3️⃣ Automation Manager (automation-manager.js)**

#### **مسئول:**
- مدیریت چرخه اتوماتیک معاملات
- انتخاب نماد (Symbol) برای معامله
- بررسی وضعیت سیگنال
- باز و بسته‌سازی پوزیشن‌ها
- محاسبه اندازه پوزیشن (Kelly Criterion)
- ذخیره‌سازی و بازیابی داده‌ها

#### **کلاس:** `AutomationManager`

#### **خصوصیات:**
```javascript
this.symbols              // لیست نمادهای برای معامله
this.isRunning            // وضعیت اتوماسیون (در حال اجرا/متوقف)
this.selectedSignal       // سیگنال آماده برای ورود
this.currentSymbolData    // داده‌های بازار نماد فعلی
this.currentSymbolHistory // تاریخچه معاملات
this.automationInterval   // بازه زمانی چرخه (5 دقیقه)
```

#### **متدهای اصلی:**

| متد | ورودی | خروجی | توضیح |
|-----|-------|-------|--------|
| `startAutomation()` | - | void | شروع اتوماسیون هر 5 دقیقه |
| `stopAutomation()` | - | void | متوقف کردن اتوماسیون |
| `runCycle()` | - | boolean | اجرای یک چرخه معامله |
| `selectNextSymbol()` | - | Object | انتخاب نماد بعدی برای معامله |
| `setupForCycle()` | - | void | پاک کردن داده‌های قدیم |
| `addSymbol()` | symbolName | void | افزودن نماد جدید |
| `updateSelectedSignal()` | - | void | تحدیث سیگنال آماده برای ورود |
| `openPosition()` | symbol, config, margin | Object | باز کردن پوزیشن جدید |
| `closeOppositePositions()` | symbol, direction | number | بسته‌سازی پوزیشن‌های مخالف |

#### **چرخه اصلی معامله (runCycle):**

```
START
 ↓
[1] انتخاب نماد بعدی
 ↓
[2] پاک کردن تمام داده‌های قدیم (setupForCycle)
    ├─ currentSymbolData = []
    ├─ currentSymbolHistory = []
    ├─ signals = []
    ├─ selectedSignal = null
    └─ UI sections cleared
 ↓
[3] دریافت داده‌های بازار (1000 شمع ساعتی)
 ↓
[4] تولید سیگنال‌ها (analyzeMarketData)
 ↓
[5] اگر سیگنالی تولید نشد ← SKIP this symbol
 ↓
[6] دریافت تاریخچه معاملات قبلی
 ↓
[7] رندر کردن UI (نمودارها، سیگنال‌ها)
 ↓
[8] ✓✓✓ بررسی وضعیت سیگنال (updateSelectedSignal)
    ├─ اگر آخرین سیگنال "در انتظار" است → انتخاب شود
    └─ اگر سیگنال موجود نیست ← SKIP this symbol
 ↓
[9] دریافت قیمت فعلی
 ↓
[10] بسته‌سازی پوزیشن‌های مخالف (اگر وجود داشتند)
 ↓
[11] دریافت موجودی حساب
 ↓
[12] محاسبه اندازه پوزیشن (Kelly Criterion)
     SizePercent = (WinRate × AvgWin - LossRate × AvgLoss) / AvgWin
     Position Size = Free Balance × SizePercent
 ↓
[13] باز کردن پوزیشن جدید
     ├─ Type: Long یا Short
     ├─ Entry Price: قیمت فعلی
     ├─ TP: مقدار محاسبه‌شده
     └─ SL: مقدار محاسبه‌شده
 ↓
[14] ذخیره داده‌ها در localStorage و دیتابیس
 ↓
[15] Mark symbol as "waiting" for next cycle
 ↓
END (موفق)
```

**اگر خطایی رخ داد:**
```
خطا رخ داد
 ↓
symbol.errorCount++
 ↓
اگر errorCount >= allowedErrors (3)
└─ symbol.status = "locked" ← کاربر باید دستی باز کند
 ↓
اگر errorCount < allowedErrors
└─ امید‌وار برای چرخه بعدی
```

### **صفحه 2️⃣: تنظیمات (settings.html)**

#### **مقصد:**
ذخیره تنظیمات API و پارامترهای تجزیه‌و‌تحلیل

#### **فیلدهای قابل تنظیم:**

**بخش اطلاعات API:**
```
apiKey       ← کلید API از صرافی
secretKey    ← کلید مخفی (HMAC-SHA256)
baseUrl      ← آدرس صرافی (پیش‌فرض: https://api.toobit.com)
```

**بخش پارامترهای سیگنال:**
```
interval      ← بازه زمانی شمع‌ها (پیش‌فرض: 1h)
limit         ← تعداد شمع‌های دریافت‌شده (پیش‌فرض: 1000)
lookback      ← بازه زمانی برای بررسی (پیش‌فرض: 50)
volMult       ← ضریب حجم (پیش‌فرض: 0.2)
avgVolPeriod  ← دوره میانگین حجم (پیش‌فرض: 50)
```

**بخش شاخص‌های تکنیکال:**
```
rsiThreshold  ← حد RSI برای سیگنال (پیش‌فرض: 50)
rsiPeriod     ← دوره RSI (پیش‌فرض: 14)
atrPeriod     ← دوره ATR (پیش‌فرض: 14)
```

**بخش Target/Stop Loss:**
```
tpLongMult    ← ضریب TP برای Long (پیش‌فرض: 20)
slLongMult    ← ضریب SL برای Long (پیش‌فرض: 6)
tpShortMult   ← ضریب TP برای Short (پیش‌فرض: 24)
slShortMult   ← ضریب SL برای Short (پیش‌فرض: 4)
```

#### **عملکرد:**
```

 ↓
دکمه "ذخیره"
 ↓
localStorage.setItem('marketSignalSettings', JSON.stringify(settings))
 ↓
دیتابیس SQLite
 ↓
✓ تنظیمات برای تمام صفحات موجود
```

## فرایندهای اصلی

### **فرایند 1: دریافت داده‌های بازار**

```
Step 1: بررسی تنظیمات ذخیره‌شده
        └─ apiKey, secretKey, baseUrl
        
Step 2: ایجاد درخواست API
        ├─ Symbol: BTC-SWAP-USDT
        ├─ Interval: 1h
        └─ Limit: 1000
        
Step 3: ارسال به Toobit API
        └─ GET https://api.toobit.com/api/v1/forwards/klines
        
Step 4: دریافت داده‌های شمعی:
        ├─ [timestamp, open, high, low, close, amount]
        ├─ [1704067200000, 42000, 42500, 41500, 42200, 5000]
        └─ ... (998 سطر دیگر)
        
Step 5: ذخیره در this.marketData
        └─ برای استفاده در محاسبات
```

### **فرایند 2: تولید سیگنال**

```
Step 1: محاسبه RSI (14):
        ├─ تغییرات قیمت
        ├─ میانگین افزایش‌ها و کاهش‌ها
        └─ RSI = 100 - (100 / (1 + RS))
        
Step 2: محاسبه ATR (14):
        ├─ دامنه‌های واقعی
        └─ میانگین متحرک دامنه‌ها
        
Step 3: محاسبه SMA (50):
        └─ میانگین متحرک 50 دوره‌ای حجم
        
Step 4: شناسایی نقاط تغیر:
        ├─ Crossover بالای روز قبل (SیGNAL LONG)
        └─ Crossunder پایین روز قبل (SIGNAL SHORT)
        
Step 5: فیلتر شرایط:
        ├─ حجم > 20% میانگین ✓
        ├─ RSI < 50 برای Long یا > 50 برای Short ✓
        ├─ ATR مثبت ✓
        └─ در بازه lookback (50 دوره) ✓
        
Step 6: محاسبه TP و SL:
        ├─ Long: TP = Price + (ATR × 20), SL = Price - (ATR × 6)
        └─ Short: TP = Price - (ATR × 24), SL = Price + (ATR × 4)
        
Step 7: ذخیره سیگنال
        └─ this.signals.push({ type, timestamp, price, tp, sl })
```

### **فرایند 3: مدیریت چرخه اتوماسیون**

```
TIME: T+0
├─ شروع چرخه
├─ انتخاب نماد (DOT)
└─ setupForCycle() - پاک‌سازی

TIME: T+1 دقیقه
├─ دریافت داده‌های بازار ✓
├─ تولید سیگنال‌ها ✓
└─ دریافت تاریخچه معاملات ✓

TIME: T+2 دقیقه
├─ رندر کردن UI
├─ بررسی وضعیت سیگنال
└─ اگر سیگنال آماده:
   ├─ دریافت قیمت فعلی
   ├─ بسته‌سازی پوزیشن‌های مخالف
   ├─ محاسبه اندازه پوزیشن
   ├─ باز کردن پوزیشن جدید
   └─ وضعیت = "منتظر چرخه بعدی"
   
OR اگر سیگنال نیست:
└─ عبور از این نماد و برو نماد بعدی

TIME: T+5 دقیقه
└─ چرخه بعدی شروع (برای نماد بعدی)
```
